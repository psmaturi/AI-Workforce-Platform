## SECTION 1: FRAMEWORK OVERVIEW

### 1.1 Purpose

The SteelCore Competency Skill Framework (CSF) is the organization's definitive reference for defining, measuring, and developing the skills and competencies required at each grade level across all departments. It serves as the foundation for:

- Performance assessments and appraisals.
- Promotion eligibility evaluation and Technical Assessment design.
- Individual Development Plan (IDP) creation.
- Learning program design and course selection.
- Recruitment and selection standards.
- Succession planning and talent mapping.

### 1.2 How to Use This Framework

1. **Self-Assessment:** Employees assess their current competency level in each skill area relevant to their role.
2. **Manager Assessment:** Managers validate employee self-assessments during performance review.
3. **Gap Identification:** The gap between current and required competency level at the next grade defines the development priority.
4. **IDP Creation:** Learning programs, certifications, and on-the-job experiences are selected to close identified gaps.

## SECTION 2: COMPETENCY LEVELS DEFINED

| Level | Code | Label | Behavioral Indicator |
|---|---|---|---|
| 1 | BEG | Beginner | Understands fundamental theory. Requires direct supervision. Makes few independent decisions. |

## SECTION 3: MECHANICAL ENGINEERING COMPETENCY FRAMEWORK

### 3.1 Role Progression
```
Grade 1–2: Mechanical Trainee / Junior Mechanical Technician
Grade 3–4: Mechanical Technician / Mechanical Engineer
Grade 5–6: Senior Mechanical Engineer / Lead Mechanical Engineer
Grade 7:   Mechanical Specialist / Principal Mechanical Engineer
Grade 8:   Maintenance Manager / Engineering Manager
```

### 3.2 Core Skill Matrix

| Skill Area | Grade 1–2 (BEG) | Grade 3–4 (INT) | Grade 5–6 (ADV) | Grade 7+ (EXP) |
|---|---|---|---|---|
| Engineering Drawing and Blueprints | Read standard drawings | Interpret complex P&IDs | Create and modify drawings | Approve engineering drawings |
| Material Science | Basic material properties | Material selection for components | Advanced metallurgy for steel components | Material failure forensics |
| Preventive Maintenance | Execute PM checklists | Plan PM schedules for equipment | Design PM programs | Optimize PM strategy using reliability data |
| Hydraulics and Pneumatics | Identify components, assist repairs | Diagnose and repair hydraulic systems | Commission and optimize hydraulic circuits | Design hydraulic systems |
| Rotating Equipment | Assist in maintenance | Independently maintain pumps, fans, compressors | Advanced diagnostics — vibration, alignment | Root cause analysis, life extension strategy |
| Root Cause Analysis (RCA) | Participate in RCA teams | Lead simple RCA investigations | Lead complex RCA for major failures | Drive systemic RCA capability building |
| Vibration Analysis | Observe and record data | Interpret vibration data (ISO Category II) | Advanced condition monitoring | Design condition monitoring programs |
| SAP PM Module | Enter work orders | Create and close work orders | Analyze maintenance data in SAP | Configure SAP PM for department needs |
| Predictive Maintenance | Assisted data collection | Apply PDM tools under supervision | Independent PDM program management | AI-based predictive maintenance strategy |
| Rolling Mill Equipment | Awareness of mill components | Maintenance of standard mill components | Lead mill rolls and chock maintenance | Mill performance optimization |

### 3.3 Future Skills (Emerging — All Grades)

- AI-Based Equipment Failure Prediction using machine learning models.
- Digital Twin for rotating and static equipment simulation.
- IIoT Sensor Integration for real-time equipment health monitoring.
- Augmented Reality (AR) maintenance guidance tools.
- Autonomous Inspection Systems using robotics and drones.
